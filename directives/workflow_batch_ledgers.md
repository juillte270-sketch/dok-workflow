# 거래원장 업데이트 워크플로우

## 개요
마스터 파일(도크발주관리데이터.xlsx)의 발주 시트에서 매장별 일일 판매금액을 집계하여
Google Drive 각 매장 폴더의 거래원장 템플릿에 자동 기입한다.

## 실행 스크립트
`execution/batch_generate_ledgers_v3.py`

## 사용법
```bash
python execution/batch_generate_ledgers_v3.py \
  --master "G:/내 드라이브/1. 도크_주문 명세서/0. 매입단가_자료/도크발주관리데이터.xlsx" \
  --start "2026-02-01" --end "2026-02-24"
```

### 파라미터
| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `--master` | X | 마스터 파일 경로 (기본값: G드라이브 경로) |
| `--start` | X | 시작일 (YYYY-MM-DD, 기본값: 2026-02-01) |
| `--end` | X | 종료일 (YYYY-MM-DD, 기본값: 2026-02-09) |
| `--out` | X | ZIP 파일명 (기본값: 자동 생성) |

## 입력
- `도크발주관리데이터.xlsx` → "발주" 시트 (매장명, 기준일, 총 판매금액)
- Google Drive 각 매장 폴더의 `(거래원장 템플릿)` 파일

## 출력
- 각 매장 월 폴더에 `YYYYMM_매장명_월말정산_거래원장.xlsx` 저장
- `data/outputs/거래원장_YYYY년M월_DD-DD일.zip` (전체 ZIP)

## 처리 흐름

### 1. 마스터 데이터 로딩
- "발주" 시트에서 매장명, 기준일, 총 판매금액 로드
- pandas DataFrame으로 처리

### 2. 템플릿 검색
- 각 매장 폴더를 재귀 탐색하여 `(거래원장 템플릿)` 파일 검색
- 파일명에 "(거래원장 템플릿)" 포함 + .xlsx 확장자

### 3. 매장명 매칭
- normalize_name: 공백, 언더스코어, 점(.) 제거 후 lowercase 비교
- 다중 지점 매장(부엉이산장, 오레노이키루미치 등)은 템플릿 경로로 지점 구분

### 4. 원장 생성
- 템플릿 복사 → 기간 내 일별 판매금액 합산
- 데이터 행: Row 17~43 (최대 27일)
- 날짜(B열), 판매금액(M열) 입력
- 제목(B5): "매장명\nMM월 월말 정산 내역"
- 기간(D7): "YYYY년 MM월 DD일 ~ MM월 DD일"
- 하단 합계(F47, F49): 총합계 입력

## 주의사항
1. **송부용 명세서와 함께 실행**: 최종 거래명세서 생성 시 반드시 거래원장도 함께 업데이트
2. **기간 설정**: `--start`는 항상 월초(MM-01), `--end`는 대상일
3. **매장명 불일치**: 마스터 파일의 매장명이 불일치하면 normalize_name으로 공백/언더스코어 제거 후 비교
4. **소유프루트 변형**: "소유프루트", "소유 프루트", "소유" 모두 매핑

## 전체 파이프라인에서의 위치
```
[송부용] 최종 거래명세서 + 거래원장 ← 이 워크플로우 (별도 요청 시)
```
