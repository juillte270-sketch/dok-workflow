# 자산화 워크플로우 (Assetization Workflow)

> 출처: 배달의민족 자산화 사례 + Kent Beck 1000x + Anthropic Pre-prompting
> 영상: https://youtu.be/3HzELVptsb4 (우아한형제들 임동준 개발자)

## 핵심 철학

"에센스를 뽑아서 일관된 결과물을 만들 수 있게 하는 것이 자산화의 핵심이다."

배민 디자이너가 sculpy 에센스를 Adobe Firefly에 넣어 일관된 디자인 자산을 만들듯이,
우리는 워크플로우 에센스를 디렉티브/스킬에 넣어 일관된 업무 결과를 만든다.

## 관련 스킬 (Skills)

| 스킬 | 용도 | 적용 시점 |
|------|------|----------|
| `pre-prompting` | 새 작업 전 3가지 사전 준비 | 새 스크립트/워크플로우 시작 전 |
| `debug-5step` | 구조화된 5단계 디버깅 | 버그 발생 시 |
| `extract-essence` | 경험에서 핵심 패턴 추출 | 버그 수정 후, 새 패턴 발견 시 |
| `naming-3step` | 의도 드러내는 네이밍 | 새 함수/변수/파일 작성 시 |
| `dev-plan` | 4단계 개발 프로세스 (Research→Plan→Annotate→Implement) | 시스템 개발/수정 시 |
| `assetize` | 세션 종료 시 자산화 총정리 | 작업 완료 후 |

## 프리프롬프팅 3요건 (Anthropic 공식)

**새 작업 시작 전 반드시 확인:**

1. **성공 기준 정의** — "이것이 성공하면 구체적으로 무엇이 달라지는가?"
2. **테스트 가능한 환경** — "`--dry-run`으로 먼저 검증할 수 있는가?"
3. **좋은 첫 번째 초안** — "기존 디렉티브/스크립트를 참고했는가?"

## Kent Beck 1000x 프레임워크

### 야심찬 비전
전체 일일 파이프라인이 최소 개입으로 돌아가는 시스템.

### 이정표 (현재 상태)
- [x] 발주 파싱 + 배송리스트 자동화
- [x] 발주시트 입력 + 가명세서 생성
- [x] 단가시트 행 생성 + 식봄 가격 입력
- [x] 경매가 API 자동 입력
- [x] 매입가/판매단가 자동 입력 (FIXED_PRICES 포함)
- [x] 재고시트 자동 입력 (1차/직납 + HELO 2차출고)
- [ ] 전체 파이프라인 원클릭 실행
- [ ] 카카오톡 발주 자동 수신 → 파이프라인 자동 시작

### 복잡성 관리
- 각 스크립트는 하나의 관심사만 처리
- 디렉티브가 스크립트 간 연결 정의
- 스킬이 교차 관심사 처리 (디버깅, 검증)
- 셀프-어닐링: 에러가 시스템을 더 강하게 만듦

## 디버깅 5단계 이정표

```
1. 문제를 한 문장으로 정의
   → "배추 매입가가 12,000원이어야 하는데 15,000원으로 입력됨"

2. 올바른 동작 정의 (Given-When-Then)
   → Given: 단가시트에 배추=12,000, 양배추=15,000
   → When: fill_prices.py 실행
   → Then: 배추 행에 12,000 입력

3. 최소 재현환경 구축
   → lookup_purchase_price() 함수만 격리하여 "배추" 입력 테스트

4. 원인 가설 나열
   → H1: 부분매칭이 양배추를 먼저 반환
   → H2: 정확매칭이 단위 불일치로 실패

5. 가설 하나씩 검증
   → H1 ✅ + H2 ✅ → 유사도 기반 매칭 + 단위 폴백으로 수정
```

## Ward Cunningham 네이밍 에센스

```
Step 1: 의도를 최대한 드러낸다 (길어져도 OK)
Step 2: 구현 부분을 숨긴다
Step 3: 반환 타입에 대한 명확한 힌트를 제공한다

예: linearSearchForElement → searchFor → includes
```

## 자산화 파이프라인

```
업무 수행 → 결과 확인 → 패턴 발견 → 에센스 추출 → 자산 생성/갱신
    ↑                                                        ↓
    └──────────── 시스템이 더 강해짐 ←────────────────────────┘
```

### 자산 유형별 위치

| 자산 유형 | 위치 | 예시 |
|----------|------|------|
| 워크플로우 절차 | `directives/workflow_*.md` | 매입가 입력 절차 |
| 검증 규칙 | `.claude/skills/verify-*/` | 고정단가 일치 검증 |
| 방법론 | `.claude/skills/*/` | 디버깅 5단계, 프리프롬프팅 |
| 누적 학습 | `MEMORY.md` | 버그 패턴, 매핑 규칙 |
| 개발 계획 | `plans/` | 리서치, 구현 계획, 검토 기록 |
| 설정/매핑 | `mappings.json`, 스크립트 상수 | FIXED_PRICES, SEARCH_CONFIG |
