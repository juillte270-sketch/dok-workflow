# 단가시트 행 생성 워크플로우

## 개요
당일 발주 데이터(processed_orders)를 바탕으로 도크발주관리데이터.xlsx의 "단가" 시트에
필요한 품목 행을 자동 생성한다. 가격 컬럼(F~J)은 비어있으며, 이후 경매가/식봄가 스크립트에서 채운다.

## 실행 스크립트
`execution/create_price_sheet.py`

## 사용법
```bash
python execution/create_price_sheet.py \
  --input "data/inputs/processed_orders_YYYYMMDD.txt" \
  --master "G:/내 드라이브/1. 도크_주문 명세서/0. 매입단가_자료/도크발주관리데이터.xlsx" \
  --date 2026-02-23
```

### 파라미터
| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `--input` | O | processed_orders 파일 경로 |
| `--master` | O | 도크발주관리데이터.xlsx 경로 |
| `--date` | O | 대상일 (YYYY-MM-DD) |
| `--filter-only` | X | 삽입 없이 기존 행만 필터링 |

## 입력
- `data/inputs/processed_orders_YYYYMMDD.txt` (공급처별 분류된 발주 데이터)
- `도크발주관리데이터.xlsx` → "단가양식" 시트 (템플릿), "단가" 시트 (대상)

## 출력
- "단가" 시트 상단에 당일 날짜/품목/등급/단위 행 추가 (가격 컬럼은 비어있음)

## 처리 흐름

### 1단계: 기존 행 삭제
- 동일 날짜의 기존 행을 먼저 삭제 (중복 방지)
- datetime 객체, `"MM월 DD일"` 문자열 모두 매칭

### 2단계: 양식 복사
- "단가양식" 시트의 모든 행(전체 공급처/품목)을 "단가" 시트 상단(row 2~)에 삽입
- 셀 값, 스타일(폰트/테두리/채우기/정렬), 행 높이, 병합 셀 모두 복사
- 날짜 컬럼(Col B): 각 품목 행에 대상일 입력, 서식 `mm"월" dd"일"`
- 헤더 행("동원", "재고", "날짜" 포함)은 날짜 입력 스킵

### 3단계: 공급업체 컬럼 병합 해제
- Col J(10, 공급업체) 컬럼의 모든 병합을 강제 해제
- 해제 후 병합 범위 내 모든 셀에 값과 스타일 복사 (개별 행 필터링을 위해 필수)

### 4단계: 필터링 (V3 로직)
발주하지 않은 공급처/품목 행을 삭제한다.

#### 4-1. 보호 행 (삭제 불가)
| 조건 | 사유 |
|------|------|
| "소분" 포함 | 소분 행은 항상 유지 |
| "공급업체" 포함 | 헤더 행 보호 |
| "식봄" 포함 | 식봄 관련 행 보호 |

> **동원 1배치**: 당분간 단가조사 안 함. 보호 해제하여 필터링 시 삭제됨 (2026-02-24~).

#### 4-2. 공급처 매칭
발주 텍스트의 공급처명과 양식의 공급업체(Col J)를 비교한다.

**SUPPLIER_ALIASES** (공급처 이름 매핑):
| 양식명 | 발주명 (별칭) |
|--------|-------------|
| 경향농산 | 다모아버섯 |
| 다모아버섯 | 경향농산 |
| 풍경농산 | 풍경 |
| 명진농산 | 명진 |
| 영운농산 | 영운 |
| 나물향기 | 나물 |
| 태현상회 | 태현 |

매칭 순서: 직접 매칭 → 별칭 매칭

#### 4-3. 품목 매칭 (2-Pass)
1. **Forward**: 발주 키워드가 양식 품목명에 포함되는지 (`keyword in item_str`)
2. **Reverse**: 양식 품목명이 발주 키워드에 포함되는지 (`item_str in keyword`)

Forward가 우선이며, Reverse는 Forward 실패 시에만 시도한다.
이 순서가 중요한 이유: 미나리/돌미나리 혼동 방지 (Forward에서 "미나리"가 "돌미나리"에 매칭되는 것을 Reverse로 보완).

#### 4-4. 마늘 특수 처리
마늘은 등급/단위 조합별로 여러 행을 유지해야 한다.

보존 조합:
| 등급 | 단위 |
|------|------|
| 상 | 1K |
| 보통 | 1K |
| 상 | 20K |
| 보통 | 20K |

위 조합에 해당하면 중복제거 대상에서 제외.

#### 4-5. 등급 기반 중복제거
동일 (공급처, 품목) 쌍에 후보가 여러 개이면 등급 우선순위로 선별:
| 우선순위 | 등급 |
|---------|------|
| 1 (최우선) | 특 |
| 2 | 상 |
| 3 | 보통 |
| 4 | 명시 없음 |

발주 횟수(`requested_count`)만큼 유지하고 나머지는 삭제한다.

### 5단계: 검증 (Missing Items Report)
필터링 후 남은 행을 발주 데이터와 비교하여 누락 품목을 보고한다.
- `🔴 Supplier Missing`: 공급처 자체가 없음
- `❌ Missing Item`: 특정 품목이 없음
- `✅ All requested items verified present!`: 누락 없음

### 6단계: 정리 (Cleanup)
- 반복 헤더 행 ("품목") 삭제
- 빈 품목 행 삭제
- 섹션 헤더("재고/소분", "공급업체")는 보호

### 7단계: 날짜 보정 (Polish)
**당일 삽입 행만 대상** — 다른 날짜의 기존 행은 절대 건드리지 않는다.
- 날짜가 이미 다른 날짜인 행은 스킵 (`date_val.date() != dt_obj.date()`)
- 당일 날짜 또는 날짜 없는 행만 대상일 재입력

## 키워드 정규화 규칙

발주 텍스트의 품목명을 단가양식 품목명과 매칭하기 위해 정규화한다.

### 직접 매핑
| 발주명 | 정규화 키워드 | 비고 |
|--------|-------------|------|
| 양배추45, 깐양배추 등 | 양배추 | "양배추" 포함 시 |
| 깐양파2호, 피양파, 양파 | 양파 | |
| 표고버섯2L, 표고 | 표고버섯 | "표고" 포함 시 |
| 완숙토마토1호 | 완숙토마토 | "토마토" 포함 시 |
| 일자콩나물 | 콩나물 | |
| 흙대파, 깐대파, 대파 | 대파 | |
| 깐쪽파, 쪽파 | 쪽파 | |
| 취청오이 | 오이 | |
| 세척무 | 무 | |
| 간마늘, 깐마늘 | 마늘 | |
| 세척당근 | 당근 | |
| 잎로메인 | 로메인 | 로메인(일반) 매칭용 |

### 역방향 확장 (Reverse Mapping)
양파 발주 시 → 깐양파, 피양파도 매칭 대상에 추가
대파 발주 시 → 흙대파, 깐대파도 추가
마늘 발주 시 → 간마늘, 깐마늘도 추가
오이 발주 시 → 취청오이도 추가
토마토/완숙토마토 → 양방향 추가
표고버섯 발주 시 → 생표고도 추가 (단가시트에 "생표고 수입" 자동 포함)

## 날짜 서식
- 저장 값: datetime 객체 (예: `datetime(2026, 2, 23)`)
- 표시 서식: `mm"월" dd"일"` → "02월 23일"
- 정렬: 가운데 정렬 (horizontal='center', vertical='center')

## 전체 단가 채우기 파이프라인에서의 위치
```
1) create_price_sheet.py       → 단가시트 행 생성 (가격 비어있음) ← 이 워크플로우
2) fill_auction_from_api.py    → 경매최고가/평균가 (Col F, G)
3) fill_sikbom_targeted.py     → 식봄 가격 (Col H)
```

## 주의사항
1. **파일 잠금**: 마스터 파일이 열려있으면 저장 실패 — 닫고 재실행
2. **단가양식 시트 필수**: "단가양식" 시트가 없으면 에러
3. **중복 실행**: 같은 날짜로 재실행하면 기존 행 삭제 후 새로 생성 (안전)
4. **표고버섯 → 생표고 수입**: 표고버섯 발주 시 "생표고 수입"도 자동으로 단가표에 포함
5. **마늘 다중 행**: 등급/단위 조합별로 별도 행 유지 (상 1K, 보통 1K, 상 20K 등)
6. **잎로메인 → 로메인**: 잎로메인 발주는 로메인(일반)으로 정규화
