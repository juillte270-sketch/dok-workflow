# 가명세서 생성 워크플로우

## 개요
processed_orders 데이터를 바탕으로 매장별 거래명세서 엑셀 파일을 생성한다.
이 단계에서는 **가격이 포함되지 않은** 가명세서를 만든다. (단가 반영은 generate_final_invoices.py에서)

## 실행 스크립트
`execution/generate_invoices.py`

## 사용법
```bash
# 기본 실행 (Drive 자동 업로드 포함 — 항상 이렇게 실행)
python execution/generate_invoices.py --date "YYYY-MM-DD"

# Drive 업로드 스킵 (디버깅/테스트 시에만 사용)
python execution/generate_invoices.py --date "YYYY-MM-DD" --local-only
```

> **중요:** 파이프라인 실행 시 반드시 `--local-only` 없이 실행할 것.
> Drive 업로드가 기본 동작이며, 가명세서는 항상 Drive에 올라가야 함.

### 파라미터
| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `--date` | X | 대상일 (YYYY-MM-DD, 기본값: 오늘) |
| `--local-only` | X | Google Drive 업로드 스킵 (테스트용) |

## 입력
- `data/inputs/processed_orders_YYYYMMDD.txt` (분류된 발주 데이터)
- Google Drive 각 매장 폴더의 **AI참고용** 템플릿 또는 최신 .xlsx

## 출력
- `data/outputs/invoices_YYYYMMDD/` (매장별 .xlsx 파일)
- `data/outputs/거래명세서_YYYYMMDD.zip` (전체 ZIP)
- Google Drive 각 매장 월 폴더에 자동 업로드

## 처리 흐름

### 1. 발주 데이터 파싱
- `processed_orders_YYYYMMDD.txt`에서 매장별 품목/수량/단위 추출
- 공급처 섹션(영운농산, 다모아버섯 등)과 내부 카테고리(재고, 시장구매)는 스킵
- 품목 파싱: `^(.+?)\s+(\d+(?:\.\d+)?)([a-zA-Z가-힣]+)` 패턴

### 2. 템플릿 검색
매장명 → Google Drive 폴더 매핑 (`folder_map`):

| 매장 | Drive 경로 |
|------|-----------|
| 샤브야키 분당점 | `1. 샤브야키 분당점` |
| 샤브야키 평택점 | `2. 샤브야키 평택점` |
| 샤브야키 주안점 | `3. 샤브야키 주안점` |
| 샤브야키 동탄점/도봉점/광교점 | `4. 샤브야키 ...` |
| 부엉이산장 강남/구월/마곡점 | `5. 부엉이 산장/N. ...` |
| 고른햇살 | `6. 고른햇살` |
| 오레노이키루미치 압구정/하남점 | `7. 오레노이키루미치/...` |
| 소유 프루트 / 소유프루트 | `8. 성동 과일 클래스 소유` |
| 봄날 | `9. 가락 과일 클래스 봄날` |
| 이너프유 | `0. 이너프유` |
| 브럭시 | `11. 브럭시` |
| 선데이버거클럽 | `12. 선데이버거클럽` |
| 육회꽃필무렵 | `13. 육회꽃필무렵 송파점` |
| 파라이 송파/역삼점 | `14. 파라이 카이카이/...` |

검색 우선순위:
1. **AI참고용** 템플릿 (재귀 검색, "AI" 포함 .xlsx)
2. 연/월 폴더 내 최신 .xlsx (mtime 기준)

### 3. 명세서 생성
- 템플릿 복사 → 날짜(D6), 매장명(B4), 전화번호(K10) 입력
- 품목 행 시작: Row 16, "합계" 행까지가 최대 용량
- 각 품목: 품목명(B), 단위(D), 수량(E), 원산지(F)
- 원산지 자동 판정: IMPORT_ITEMS 목록에 있으면 "수입산", 나머지 "국내산"
- 빈 행 숨김 (hidden), 합계/금액 셀 0으로 초기화

### 4. 수입산 품목 목록
`세척당근, 오렌지, 표고버섯2L, 표고버섯, 맛김치, 포기김치, 파김치, 레몬, 백김치, 매운고춧가루, 씻은지`

### 5. Drive 업로드
- 매장별 월 폴더 자동 탐색/생성 (다양한 폴더명 형식 대응: "2026년 2월", "26년2월" 등)
- `--local-only` 시 업로드 스킵

## 주의사항
1. **가격 없이 전달 금지**: 이 단계는 가명세서이므로, 최종 전달은 반드시 `generate_final_invoices.py`를 거쳐야 함
2. **매장명-폴더 매핑**: Exact match → Longest partial match 순서
3. **소유프루트**: 공백 유무 모두 매핑 ("소유 프루트" / "소유프루트")

## 전체 파이프라인에서의 위치
```
[2] 발주시트 입력 & 가명세서 생성 ← 이 워크플로우
     ↓
[송부용] 최종 거래명세서 + 거래원장 (별도 요청 시)
```
