# 최종 거래명세서 생성 워크플로우

## 목표
기존 가명세서에 단가 정보를 추가하고, 당월/당일 금액을 계산하여 최종 거래명세서를 PDF로 생성

## 입력
- **마스터 파일**: `G:\내 드라이브\1. 도크_주문 명세서\0. 매입단가_자료\도크발주관리데이터.xlsx`
- **대상 날짜**: YYYY-MM-DD 형식
- **기존 거래명세서**: 각 매장별 폴더의 가명세서 파일

## 출력
- **최종 거래명세서 Excel**: 단가/금액 정보 포함
- **최종 거래명세서 PDF**: 1페이지 PDF 파일
- **검증 리포트**: 금액 검증 및 오류 리포트

### 3단계: 금액 계산
```python
# 3-1. 당월금액 계산
# 해당 월 1일 ~ (대상일-1일)까지의 총판매금액 합계
당월금액 = calculate_monthly_amount(거래처, 대상날짜)

# 대상일의 공급가액 합계

# 3-3. 총사용액 계산
총사용액 = 당월금액 + 당일금액

# 3-4. 입금액 확인

    print(f"⚠️  금액 불일치: {거래처}")
    print(f"   마스터: {마스터_합계:,}원")
    print(f"   명세서: {명세서_합계:,}원")

# 6-2. 품목별 단가 검증
for 품목 in 거래처_데이터:
    예상_금액 = 품목['입고수량'] * 품목['판매가']
    실제_금액 = 품목['총판매금액']
    
    if abs(예상_금액 - 실제_금액) > 1:  # 1원 이상 차이

        print(f"   실제: {실제_금액:,}원")
```

## 7단계: 거래원장 업데이트 (자동 연동)

송부용 거래명세서 생성 완료 후, **항상** 거래원장도 함께 업데이트한다.

```bash
# 해당 월 1일 ~ 대상 날짜까지 거래원장 일괄 갱신
python execution/batch_generate_ledgers_v3.py --start YYYY-MM-01 --end YYYY-MM-DD
```

- 거래원장은 각 매장 Google Drive 폴더의 `YYYY년 M월/` 하위에 저장됨
- 로컬 zip 파일도 `data/outputs/거래원장_YYYY년M월_DD-DD일.zip`로 생성
- 템플릿 미존재 매장(광교점, 도봉점, 다비다 등)은 자동 스킵

## 주의사항

1. **양식 유지**: 기존 거래명세서의 양식과 스타일을 그대로 유지
2. **1페이지 PDF**: PDF는 반드시 1페이지로 생성
3. **금액 검증**: 마스터 파일과 최종 명세서의 금액이 일치해야 함
4. **입금액 처리**: 입금액이 없는 경우 0으로 처리
5. **당월금액 계산**: 해당 월 1일부터 전일까지만 계산
6. **거래원장 연동**: 송부용 거래명세서 생성 시 거래원장도 반드시 함께 업데이트

## 의존성

- `openpyxl`: Excel 파일 읽기/쓰기
- `win32com` 또는 `comtypes`: Excel → PDF 변환
- `pandas`: 데이터 처리
- `datetime`: 날짜 계산
