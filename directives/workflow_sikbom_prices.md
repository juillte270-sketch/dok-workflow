# 식봄 가격 입력 워크플로우

## 개요
식봄(Foodspring) 사이트에서 Selenium으로 품목별 가격을 검색하여
도크발주관리데이터.xlsx 단가 시트의 Col H(식봄)에 자동 입력한다.

## 실행 스크립트
- **메인**: `execution/fill_sikbom_targeted.py` (타겟 검색 — 품목별 검색어/업체 지정)
- **기반**: `execution/fetch_foodspring_prices.py` (FoodspringScraper 베이스 클래스)

## 사용법
```bash
python execution/fill_sikbom_targeted.py \
  --master "G:/내 드라이브/1. 도크_주문 명세서/0. 매입단가_자료/도크발주관리데이터.xlsx" \
  --date 2026-02-23
```

### 파라미터
| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `--master` | O | 도크발주관리데이터.xlsx 경로 |
| `--date` | O | 단가시트 대상일 (YYYY-MM-DD) |

## 입력
- `도크발주관리데이터.xlsx` → "단가" 시트 (Col C 품목, Col H 식봄 가격)
- 식봄 사이트 로그인 계정

## 출력
- 단가 시트 Col H(식봄) 가격 입력

## 식봄 사이트 정보
- URL: https://www.foodspring.co.kr
- 로그인: 이메일 로그인 (계정 정보는 `fetch_foodspring_prices.py`에 하드코딩)
- Selenium: headless Chrome + 모바일 에뮬레이션 (iPhone UA)
- 검색: `/search` 페이지에서 `input[type='search']`에 키워드 입력 → Enter
- 파싱: BeautifulSoup으로 상품 카드에서 업체명/가격 추출

## 주요 업체 우선순위
1. **CJ프레시웨이** — 대부분의 품목에서 1순위
2. **다봄푸드** — CJ에 없거나 특정 품목(깐대파, 레몬, 간마늘 등)
3. **세현F&B** — 미나리 등 특정 품목
4. **케이에프피(강남)** — 귤 전용 (CJ는 너무 비쌈)
5. **농장에서바로 / 쉐프의정원** — 라디치오 전용

### 검색 규칙 상세
- `search`: 식봄 검색창에 입력할 키워드
- `suppliers`: 우선순위대로 나열, 첫 번째 업체 결과 우선 사용
- `filter`: 검색 결과 중 이 문자열이 포함된 상품만 선택 (대소문자 무시)
- `exclude`: 이 문자열이 포함된 상품은 제외
- `unit_convert`: 가격에 이 배수를 곱함 (단위 환산용)
- `match_grade`: 등급(Col D) 매칭 — 해당 문자열이 포함된 등급 행만 대상
- `match_unit`: 단위(Col E) 매칭 — 대소문자 무시, 정확 일치

## 다중 행 품목 (MULTI_ROW_ITEMS)
동일 품목명이 등급/단위 조합별로 여러 행을 가지는 경우 복합키로 구분한다.

| 품목 | 구분 방식 | 행 예시 |
|------|----------|---------|
| 깐마늘 대서 | grade+unit | 상or대/1K, 보통or중/1K, 보통or중/20K |
| 애호박 | grade | 특, 상 |

복합키 형식:
- `grade+unit`: `품목|등급|단위` (예: `깐마늘 대서|상or대|1K`)
- `grade`: `품목|등급` (예: `애호박|특`)

동일 검색어+필터 조합은 캐시하여 중복 검색 방지 (예: 깐마늘(중) 1K/20K).

## 매칭 로직
1. 단가 시트에서 대상 날짜의 품목 행을 수집 (소분 제외)
2. **일반 품목**: 첫 번째 발견 행만 사용 (`if item not in row_map`) — 중복 블록 방지
3. **MULTI_ROW_ITEMS**: 등급/단위 복합키로 별도 관리 — 각 조합별 첫 번째 행 사용
4. SEARCH_CONFIG의 각 품목에 대해:
   - `match_grade`/`match_unit`이 있으면 복합키로 row_map 조회
   - 식봄 검색 실행 → 결과에서 target_suppliers 중 매칭되는 상품 찾기
   - product_filter로 상품명 필터링
   - exclude_filter로 제외 처리
   - 같은 업체 내 최저가 선택
   - unit_convert 적용 후 Col H에 입력

## 가격 추출 로직
- BeautifulSoup으로 상품 카드 파싱
- 업체명이 포함된 컨테이너에서 가격 추출
- 할인가 패턴 (`XX% 가격원`) 우선 → 없으면 두 번째 가격(회원가) → 첫 번째 가격
- 100원 이하 가격은 제외 (노이즈 방지)

## 단위 환산 주의사항
| 품목 | 식봄 단위 | 단가시트 단위 | 환산 |
|------|----------|-------------|------|
| 깐양배추45 | 2kg/ea | 10K (10kg) | ×5 (2kg × 5 = 10kg) |
| 깐양배추42 | 2kg/ea | 8K (8kg) | ×4 (2kg × 4 = 8kg) |
| 깐마늘 대서(중) 20K | 1kg/ea | 20K (20kg) | ×20 (1kg × 20 = 20kg) |
| 애호박(특) | 개당 | BOX (20개) | ×20 (인큐애호박 개당 → BOX) |

## 스킵/미매칭 처리
| 조건 | 처리 |
|------|------|
| 구분(Col A)에 "소분" 포함 | 스킵 |
| SEARCH_CONFIG에 없는 품목 | 검색 안함 (경매가로만 참고) |
| 검색 결과 없음 | NOT FOUND 로깅 |
| 로그인 실패 | 전체 중단 |

## 실행 환경 요구사항
- Chrome 브라우저 + ChromeDriver 설치
- Selenium, BeautifulSoup4 패키지
- 인터넷 연결 (식봄 사이트 접속)
- 실행 시간: 약 1~3분 (품목 수에 따라, 품목당 ~5초 대기)

## 전체 단가 채우기 파이프라인에서의 위치
```
1) create_price_sheet.py       → 단가시트 행 생성
2) fill_auction_from_api.py    → 경매최고가/평균가 (Col F, G)
3) fill_sikbom_targeted.py     → 식봄 가격 (Col H)          ← 이 워크플로우
```

경매가와 식봄가를 비교하여 매입가(Col I) 결정의 참고 자료로 활용한다.
