# 재고시트 1차/직납 입력 워크플로우

## 개요
processed_orders의 "재고, 창고소분" 섹션을 파싱하여
도크발주관리데이터.xlsx 재고 시트의 1차/직납 컬럼에 자동 입력한다.

## 실행 스크립트
`execution/fill_inventory_sheet.py`

## 사용법
```bash
python execution/fill_inventory_sheet.py --date 2026-02-23
python execution/fill_inventory_sheet.py --date 2026-02-23 --dry-run  # 미리보기
```

### 파라미터
| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `--master` | X | 마스터 파일 경로 (기본값: G드라이브) |
| `--date` | O | 대상일 (YYYY-MM-DD) |
| `--dry-run` | X | 미리보기만 (저장 안 함) |

## 입력
- `data/inputs/processed_orders_YYYYMMDD.txt` → "재고, 창고소분" 섹션
- `도크발주관리데이터.xlsx` → "재고" 시트

## 출력
- 재고시트 1차/직납 컬럼에 품목별 수량 입력

## 재고시트 구조
날짜별 6컬럼 그룹: `품목(+0) | 재고(+1) | 1차/직납(+2) | 2차출고(+3) | 입고(+4) | 현재고(+5)`
- 헤더: Row 1-5, "M/DD 재고현황" 패턴
- 품목 시작: Row 4, 약 40개 품목

## 처리 흐름

### 1. "재고, 창고소분" 섹션 파싱
- `-재고, 창고소분` 헤더 감지 후 해당 섹션만 파싱
- 품목 패턴: `품목 수량단위(매장)` (예: "감자 15kg(강남)")
- 동일 품목은 수량 합산

### 2. 날짜 컬럼 탐색
- Row 1-5에서 "M/DD 재고현황" 검색
- "2/23"이 "12/23"에서 오매칭되지 않도록 앞자리 숫자 체크
- 1차/직납 = 품목 컬럼 + 2

### 3. 품목 매핑
`inventory_item_map` (mappings.json 또는 DEFAULT_ITEM_MAP):

| 발주 품목 | 재고시트 품목 |
|----------|-------------|
| 감자 | 감자(KG) |
| 세척당근 | 당근(KG) |
| 청양고추 | 고추(KG) |
| 팽이 | 팽이버섯(팩) |
| 깐마늘(대) | 마늘1kg (특수: 수량별 분기) |
| 양상추 | 양상추(12수/통) |
| 레몬 | 레몬(개) |
| ... | (약 30개 매핑) |

### 4. 깐마늘 특수 처리
- 4kg → 마늘1kg 행 (qty = 4)
- 0.5kg → 마늘500g 행 (qty = 1)

### 5. Fuzzy 매핑
직접 매핑 실패 시 → 괄호 앞 키워드 비교 (예: "팽이버섯(팩)" ↔ "팽이버섯(개)")

## 전체 파이프라인에서의 위치
```
[1] 배송리스트 생성 + 재고시트 1차/직납 입력 ← 이 워크플로우
```
