# 발주 분류 및 학습 워크플로우

이 가이드는 발주 리스트를 AI에게 제공하여 자동 분류하고, 결과를 검토하여 시스템을 학습시키는 방법을 설명합니다.

## 🎯 워크플로우 개요

```
발주 리스트 입력
    ↓
AI 자동 분류
    ↓
결과 확인
    ↓
수정 필요? ─── No ──→ 완료
    │
   Yes
    ↓
수정된 결과 입력
    ↓
AI 자동 학습
    ↓
매핑 업데이트
    ↓
다음부터 더 정확!
```

## 🚀 사용 방법

### 방법 1: 대화형 모드 (가장 쉬움, 권장)

```bash
python execution/classify_and_learn.py --interactive
```

#### 단계별 진행:

1. **발주 리스트 입력**
   ```
   📋 발주 리스트를 입력하세요 (빈 줄로 종료):
   -샤브야키 도봉점
   무순(대) 1팩
   숙주 4박스
   청양고추(상) 1박스
   
   [빈 줄 입력]
   ```

2. **자동 분류 결과 확인**
   ```
   📦 분류 결과:
   ============================================================
   -샤브야키 도봉점
   숙주 4박스
   청양고추(상) 1박스
   
   -정복상회
   무순(대) 1팩
   
   -오복상회
   숙주 4박스
   
   -소리농산
   청양고추(상) 1박스
   ============================================================
   ```

3. **결과 검토**
   ```
   💡 이 분류 결과가 정확한가요?
      - 정확하면 'y' 입력 (학습 없이 종료)
      - 수정이 필요하면 'n' 입력 (수정 후 학습)
   
   선택 (y/n): 
   ```

4. **수정 및 학습 (필요시)**
   ```
   📝 수정된 분류 결과를 입력하세요 (빈 줄로 종료):
   -정복상회
   무순(대) 1팩
   
   -오복상회
   숙주 4박스
   
   -소리농산
   청양고추(상) 1박스
   
   [빈 줄 입력]
   
   🎓 학습 중...
   ✨ 새 품목 추가: 정복상회 <- 무순
   ✅ 매핑 업데이트 완료! 다음부터 더 정확하게 분류됩니다.
   ```

### 방법 2: 파일 모드

```bash
python execution/classify_and_learn.py --input "data/inputs/orders_today.txt" --output "classified.txt"
```

## 💡 실전 사용 시나리오

### 시나리오 1: 새로운 발주 분류

```bash
# 1. 대화형 모드 실행
python execution/classify_and_learn.py --interactive

# 2. 발주 리스트 붙여넣기
[Ctrl+V로 발주 리스트 붙여넣기]
[Enter로 빈 줄 입력]

# 3. 결과 확인
# - 정확하면 'y' → 완료
# - 수정 필요하면 'n' → 수정 후 학습
```

### 시나리오 2: 정기적 학습

매주 또는 매월:
1. 실제 발주 데이터 수집
2. AI 분류 실행
3. 실제 공급업체 분류와 비교
4. 차이점 학습
5. 시스템 정확도 향상

### 시나리오 3: 새 공급업체 추가

새로운 공급업체가 생기면:
```bash
python execution/classify_and_learn.py --interactive

# 발주 리스트 입력
-샤브야키 도봉점
새로운품목 5박스

# AI 분류 결과 (Unknown으로 분류됨)
-Unknown
새로운품목 5박스

# 수정된 결과 입력
-새공급업체
새로운품목 5박스

# 자동 학습 → 다음부터 정확하게 분류!
```

## 📊 학습 효과 예시

```

레드향 3박스

-Unknown

```

```
-샤브야키 도봉점

분류:
-이모유통
레드향 3박스
```

## 🎓 학습되는 내용

### 1. 품목-공급업체 매핑
```json
{
    "이모유통": ["레드향", "골드망고", "사과", ...]
}
```

### 2. 재고/소분 규칙
```json
{
    "item_keyword": "감자",
    "conditions": [
        {
            "unit": "10kg",
            "store": "부엉이산장 강남점",
            "target": "STOCK"
        }
    ]
}
```

### 3. 시장구매 규칙
```json
{
    "item_keyword": "새싹",
    "conditions": [
        {
            "store": "샤브야키 주안점",
            "target": "MARKET"
        }
    ]
}
```
