# Workflow 1: 발주 처리 및 배송리스트 생성

## 목표
거래처로부터 접수된 발주 내역을 입력받아 공급처별로 분류하고, 배송리스트(4~5페이지 분량)를 생성합니다.

## 입력
- **발주 데이터**: 텍스트 형식 (카카오톡, 문자 등) 또는 엑셀 파일
- **필수 매핑 정보**:
  - `공급처별 품목 매핑` (영운농산, 다모아버섯 등)
  - `배송리스트 페이지 배정 규칙` (요일별 상이)
  - `색상/단위 규칙`

## 출력
- **파일**: `data/outputs/배송리스트_{YYYYMMDD}.xlsx`
- **형식**: 
  - 페이지별로 시트 또는 영역 분리
  - 공급처별 품목 정렬
  - 색상 하이라이팅 적용 (재고소분: 빨강, 시장소분: 파랑)

## 처리 로직 (Python)

### 1. 매핑 데이터 로드
- 코드 내 딕셔너리 또는 외부 JSON/YAML 설정 파일로 관리
- 주요 매핑: `ITEM_SUPPLIER_MAP`, `STORE_PAGE_MAP`

### 2. 발주 데이터 파싱
- **입력 형식**:
  ```text
  -샤브야키 동탄점
  배추 1망
  숙주 8박스
  ```
- 정규식 등을 사용하여 `거래처`, `품목`, `수량`, `단위` 추출

### 3. 데이터 검증 (Verification)
- 등록되지 않은 거래처/품목 경고
- **품위/단위 변환**:
  - `깐양파2호` -> 3kg/5kg... 단위 확인
  - `배추(통)` -> "1통, 1통" 분리 표기 로직 적용

### 4. 배송리스트 생성
- **요일 확인**: 금요일 vs 기타 요일 페이지 구성 변경
- **엑셀 포맷팅**:
  - `openpyxl` 사용
  - 페이지별 레이아웃 배치
  - 조건부 서식 또는 직접 셀 스타일 적용 (빨강/파랑 텍스트)

## 실행 스크립트
`execution/process_orders.py`

## 사용 예시
```bash
python execution/process_orders.py --input "data/inputs/orders_20260127.txt"
```
