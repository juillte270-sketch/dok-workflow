# 2차 발주 메시지 자동화

## 개요
동원 10시 마감 후, 각 공급처에 보낼 2차 발주 메시지를 생성하고 카카오톡으로 전송한다.
사용자가 품목별 수량을 알려주면 → JSON 생성 → 스크립트가 메시지 포맷 → 카톡 전송.

## 실행 스크립트
`execution/second_order.py`

## 사용법
```bash
# 메시지 확인만 (전송 안 함)
python execution/second_order.py --input data/inputs/second_order.json --dry-run

# 카카오톡 전송
python execution/second_order.py --input data/inputs/second_order.json --send
```

## 에이전트 워크플로우

### 1. 사용자 입력 파싱
사용자가 알려주는 수량을 JSON으로 변환한다.

**사용자 입력 예시:**
> 2차 발주: 아카시아청 5, 마카로니 3. 이모유통 라임 2, 바나나 3. 정운 맛김치 5.

**변환 결과 (`data/inputs/second_order.json`):**
```json
{
  "동원": {"아카시아청": "5", "마카로니": "3"},
  "이모유통": {"라임": "2", "바나나 1발": "3"},
  "정운": {"맛김치": "5"}
}
```

### 2. JSON 작성 규칙
- **키**: 공급처명 (동원, 이모유통, 오복상회, 정운, 세연농산, 정복상회, 현진상회, 경북상회, 카드결제)
- **값**: `{"품목명": "수량"}` 딕셔너리
- 수량이 없는 품목 (현진상회/경북상회/카드결제): `{"품목명": true}`
- **생략된 공급처/품목은 메시지에서 제외됨**
- 약칭 자동 변환: `바나나` → `바나나 1발`, `방토` → `방토 2호 500g` 등

### 3. 스크립트 실행
```bash
python execution/second_order.py --input data/inputs/second_order.json --send
```

### 4. 결과 확인
- 각 공급처별 메시지가 카카오톡 "나에게 보내기"로 전송됨
- `[공급처명]` 라벨이 붙어서 어느 공급처용인지 식별 가능
- 사용자가 해당 메시지를 각 공급처 채팅방에 전달

## 공급처별 메시지 템플릿

### 동원
```
 - 아카시아청 : {qty}
 - 마카로니 : {qty}
```

### 이모유통
```
금일 2차발주입니다(지하2층i05기둥0457차량)
  *라임 : {qty}
  *바나나 1발 : {qty}
  *방토 2호 500g : {qty}
  *수박(5kg 내외) 1통 : {qty}
  *사과(4다이 7개입) : {qty}
  *파인애플(6수/개) : {qty}
```

### 오복상회
```
금일 2차발주입니다(지하2층i05기둥0457차량)
 - 고사리 : {qty}
 - 숙주 : {qty}
 - 곱슬이 콩나물 : {qty}
```

### 정운
```
-금일 발주입니다
맛김치 : {qty}
```

### 세연농산
```
금일 발주입니다
 - 미나리(대) : {qty}
 - 돌미나리(4KG) : {qty}
 - 깐쪽파 : {qty}
 - 부추 : {qty}
```

### 정복상회(랑희)
```
금일 발주입니다
-무순50 : {qty}
-베이비50 : {qty}
-베이비250 : {qty}
-베이비500 : {qty}
```

### 현진상회 (품목 나열, 수량 없음)
```
금일 발주입니다.
-쑥갓
-치커리
-깻잎
-청상추
```

### 경북상회 (품목 나열, 수량 없음)
```
금일 발주입니다.
-청피망(상)300G
-가지
-쥬키니
```

### 카드결제 (메모용)
```
-애플민트
-루꼴라
```

## 약칭 매핑
| 약칭 | 정식명 |
|------|--------|
| 바나나 | 바나나 1발 |
| 방토 | 방토 2호 500g |
| 수박 | 수박(5kg 내외) 1통 |
| 사과 | 사과(4다이 7개입) |
| 파인애플 | 파인애플(6수/개) |
| 곱슬이 | 곱슬이 콩나물 |
| 미나리 | 미나리(대) |
| 돌미나리 | 돌미나리(4KG) |
| 무순 | 무순50 |
| 청피망 | 청피망(상)300G |

## 주의사항
1. **품목 생략**: JSON에 없는 품목은 메시지에서 자동 제외
2. **공급처 생략**: JSON에 없는 공급처는 메시지 자체가 생성되지 않음
3. **카톡 전송**: "나에게 보내기" API 사용 → 사용자가 각 공급처 채팅방에 전달
4. **토큰 만료**: kakao_token.json 갱신 실패 시 kakao_auth.py 재실행 필요

## 전체 파이프라인에서의 위치
```
[오전] 1차 발주 처리 (자동화 파이프라인)
     ↓
[오후 10시] 동원 마감 → 2차 발주 ← 이 워크플로우
     ↓
[새벽] 경매가 입력, 매입가/판매단가 입력
```
