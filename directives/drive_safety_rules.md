# 드라이브 파일 안전 규칙

## ⚠️ 절대 금지 사항

1. **자동 삭제 금지**
   - `shutil.rmtree()`, `os.remove()` 등으로 드라이브 파일/폴더 삭제 금지
   - 삭제가 필요하면 **반드시 사용자에게 먼저 확인**

2. **폴더 구조 변경 금지**
   - 새 폴더 생성 전 기존 폴더 존재 여부 확인
   - 폴더명 변경, 이동 금지

## ✅ 권장 사항

1. **덮어쓰기 방식 사용**
   ```python
   shutil.copy2(src, dst)  # 기존 파일이 있으면 덮어쓰기
   ```

2. **폴더 매핑 설정 파일 사용**
   - `resources/drive_folder_mapping.json` 참조
   - 새 매장 추가 시 이 파일만 수정

3. **파일 복사 전 경로 확인**
   ```python
   target_path = os.path.join(DRIVE_ROOT, FOLDER_MAP[store], "2026년 2월")
   print(f"저장 위치: {target_path}")  # 로그 출력
   os.makedirs(target_path, exist_ok=True)  # 없으면 생성
   ```

## 📋 폴더 매핑 예시

| 매장명 (파일) | 드라이브 폴더 |
|--------------|---------------|
| 샤브야키_분당점 | 1. 샤브야키_분당점 |
| 부엉이산장_강남점 | 5. 부엉이 산장/1. 부엉이산장 강남 |
| 오레노이키루미치_압구정점 | 7. 오레노이키루미치/오레노이키루미치 압구정점 |

## 🔧 문제 발생 시

1. 잘못된 폴더 생성 시: 사용자에게 알리고 수동 삭제 요청
2. 파일 덮어쓰기 실패 시: 권한 문제 확인
3. 매핑 누락 시: `drive_folder_mapping.json`에 추가
