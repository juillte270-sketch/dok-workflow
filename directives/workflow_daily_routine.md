# DoKH 아침 9시 업무 루틴

## 📅 실행 일정
- **매일 아침 09:00**
- 사용자가 "최종 정제 발주본"을 제공하면 실행 시작

## 🔄 실행 단계 (1~3단계 통합)
다음 명령어를 실행하여 1단계부터 3-2단계까지 한 번에 처리합니다:

```bash
python execution/run_full_workflow.py --date "YYYY-MM-DD"
```

### 세부 단계
1. **1단계: 발주 처리 및 배송리스트 생성**
   - 발주 텍스트 파일 파싱
   - 배송리스트(DOCX) 생성
   - `data/outputs/배송리스트_YYYYMMDD.docx`

2. **2단계: 발주 시트 입력**
   - Google Drive 마스터 파일(`도크발주관리데이터.xlsx`) 업데이트
   - 자동 분류 및 이익률 계산

3. **3단계: 단가 작업 및 가명세서 생성**
   - **3-1단계**: 단가 시트 생성 (매입단가용)
   - **3-2단계**: 가명세서 생성 (`generate_invoices.py` 실행)
     - 단가가 0원인 상태의 엑셀 파일 생성
     - `data/outputs/거래명세서_YYYYMMDD.zip` 생성

## 🛑 작업 중단 및 대기 + 영수증 자동 감시
- 여기까지 진행 후 **대기**합니다.
- 영수증 자동 감시 데몬을 실행하면, 공급처 영수증 수신 시 자동으로 매입가가 입력됩니다:
  ```bash
  python execution/receipt_watcher.py --date "YYYY-MM-DD"
  ```
  - 카카오톡 이미지 클릭 → 자동 OCR → 단가시트 입력
  - ERP URL 복사 → 자동 파싱 → 단가시트 입력
- 대시보드 "5. 매입가 입력 & 판매가" 페이지에서도 빠른 입력 가능

## ⏳ [4단계] 송부용 거래명세서 생성 (별도 요청 시)
- 사용자가 "단가 확인 완료" 또는 "송부용 명세서 만들어줘"라고 요청하면 실행합니다.
- **실행 명령어**:
  ```bash
  python execution/generate_invoices_from_guide.py --date "YYYY-MM-DD"
  ```
- 이 단계는 **단가가 모두 입력된 후**에 실행되어야 정확한 금액이 산출됩니다.

## 📂 파일 위치 필독
- **발주 리스트**: `data/inputs/`
- **결과물(가명세서 등)**: `data/outputs/`
- **마스터 파일**: Google Drive > `1. 도크_주문 명세서` > `0. 매입단가_자료` > `도크발주관리데이터.xlsx`
