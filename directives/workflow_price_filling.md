# DoKH 매입가/판매단가 입력 워크플로우

## 개요
발주시트에 매입단가, 판매단가, 공급업체를 채우는 작업.
단가시트에서 매입가를 조회하고, 과거 거래 이력으로 판매단가를 결정한다.

## 실행 스크립트
`execution/fill_prices.py`

## 사용법
```bash
python execution/fill_prices.py --date "2026-02-13" --master-file "path/to/master.xlsx"
```

## 입력
- `도크발주관리데이터.xlsx` (발주시트 + 단가시트)
- 대상 날짜

## 발주시트 컬럼 구조

| 컬럼 | 내용 | 입력방식 |
|------|------|----------|
| A | 매장명 | 기존값 |
| D | 기준일 | 기존값 |
| E | 품목 | 기존값 |
| F | 공급업체 | **값 입력** (item_supplier_map 참조) |
| G | 단위 | 기존값 |
| H | 입고수량 | 기존값 |
| I | 매입단가 | **값 입력** (단가시트 소분/재고 참조) |
| J | 총매입금액 | **수식**: =H*I |
| K | 판매단가 | **값 입력** |
| L | 총판매금액 | **수식**: =K*H |
| M | 마진율 | **수식**: =IF(L>0,(L-J)/L*100,0), 서식 0.0 |
| N | 이익률 | **수식**: 거래처 첫행만, 서식 0.0 |

## 공급업체 결정 로직

1. 기존 F열에 구체적 공급업체명(우신농산, 가야웰빙 등)이 있으면 유지
2. generic 라벨(직납/재고, 소분/재고, 재고, 동원1배치)이면 `item_supplier_map`에서 조회
3. `normalize_item()`으로 퍼지 매칭 (괄호/숫자 제거, 샤인머스캣↔머스켓)
4. 매칭 없으면 기존값 유지

공급업체 소스: `skills/order_processing/resources/mappings.json` → `item_supplier_map`

## 매입단가 결정 로직

### 1순위: 고정 매입단가 (FIXED_PRICES)
단가시트와 무관하게 항상 동일한 가격을 적용하는 품목. 단가시트에 없는 품목도 자동 입력된다.

| 품목 | 고정가 | 비고 |
|------|--------|------|
| 숙주 | 4,500 | |
| 굵은숙주 | 4,700 | |
| 새싹(대) | 4,000 | |
| 무순(대) | 800 | |
| 중란 | 5,600 | |
| 대란 | 5,800 | |
| 곱슬이콩나물 | 2,800 | |
| 일자콩나물 | 2,800 | |
| 아보카도 | 1,900 | 수입산 |
| 중숙아보카도 | 1,900 | 수입산 |
| 파김치 | 19,000 | |
| 맛김치 | 16,000 | |
| 냉동알마늘 | 29,000 | |
| 쌀 | 59,000 | |
| 매운고춧가루 | 9,500 | 수입산 |
| 굵은고춧가루 | 7,800 | 수입산 |

매칭 순서: 정확 매칭 → 부분 매칭 (긴 키워드 우선)

### 2순위: 단가시트 조회
단가시트의 모든 섹션(소분/재고, 직납/재고)에서 당일 매입가를 조회한다.
`parse_price_unit()`으로 단가시트 단위를 파싱하고, 발주시트 단위에 맞게 변환한다.

### 단위 변환 로직

| 발주 단위 | 단가시트 단위 | 변환 |
|-----------|-------------|------|
| kg | 10K (10kg) | price / 10 (per-kg 변환) |
| kg | 1K (1kg) | price 그대로 |
| 박스/망 | 10K, 20K 등 | price 그대로 (벌크 가격) |
| 박스/망 | 소분/재고 1K | 적용 불가 (0) |
| kg | 1알, 1봉 등 | 적용 불가 (단위 미스매치) |
| 개 | 1K (kg 기준) | 적용 불가 (단위 미스매치) |

### 단가시트 구조
| 섹션 | 매입가 | 단위 예시 | 사용 |
|------|--------|----------|------|
| 소분/재고 | numeric (per-unit) | 1K, 1팩, 1알 | 소분 단위(kg,개)에 적용 |
| 직납/재고 | numeric (벌크 가격) | 10K, 20K, 4K | 단위 변환 후 적용 |
| 동원1배치 | text (규격 설명) | - | 적용 불가 |

## 판매단가 결정 로직

| 거래처 | 로직 |
|--------|------|
| 샤브야키 (동탄점 제외) | 샤브통일가 (기존 최빈값) |
| 샤브야키 동탄점 | 최근 거래가 또는 신규(매입가 / 0.75) |
| 부엉이산장 | 부엉통일가 (기존 최빈값) |
| 기타 거래처 | 최근 거래가 또는 신규(매입가 / 0.80) |

## 검증 로직

| 조건 | 처리 |
|------|------|
| 마진율 < 0% | 재계산(20% 마진) |
| 마진율 < 10% | 저마진 경고 |
| 마진율 > 70% | 고마진 경고 (부엉이산장은 기존가 유지) |
