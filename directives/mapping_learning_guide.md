# 매핑 학습 시스템 사용 가이드

DoKH 발주 시스템은 **자동 학습 기능**을 지원합니다. 실제 발주 데이터와 공급업체 분류 결과를 제공하면, 시스템이 자동으로 규칙을 학습하여 `mappings.json` 파일을 업데이트합니다.

## 🎓 학습 시스템이란?

매핑 학습 시스템은 다음을 자동으로 학습합니다:

1. **품목-공급업체 매핑**: 어떤 품목이 어느 공급업체에서 오는지
2. **재고/소분 규칙**: 어떤 조건에서 재고/창고소분으로 분류되는지
3. **시장구매 규칙**: 어떤 조건에서 시장구매로 분류되는지

## 🚀 사용 방법

### 방법 1: 대화형 모드 (권장)

```bash
python execution/learn_mappings.py --interactive
```

실행 후:
1. 고객 발주 리스트를 복사하여 붙여넣기
2. 빈 줄 입력 (Enter)
3. 공급업체 분류 결과를 복사하여 붙여넣기
4. 빈 줄 입력 (Enter)
5. 학습 결과 확인 후 저장 여부 선택

### 방법 2: 파일 모드

```bash
python execution/learn_mappings.py --customer-orders "customer.txt" --supplier-orders "supplier.txt"
```

## 🎯 학습 결과

학습 시스템은 다음을 자동으로 수행합니다:

### 1. 품목 정규화
- `양배추45` → `양배추`
- `깐마늘(중)` → `마늘`
- `청양고추(상)` → `청양고추`

### 2. 공급업체 매핑 추가
```json
{
    "item_supplier_map": {
        "영운농산": ["청경채", "쑥갓", "알배기", ...],
        "다모아버섯": ["팽이", "새송이", "꽃느타리", ...]
    }
}
```

### 3. 재고/소분 규칙 추가
```json
{
    "stock_market_rules": [
        {
            "item_keyword": "감자",
            "conditions": [
                {
                    "unit": "10kg",
                    "store": "부엉이산장 강남점",
                    "target": "STOCK"
                }
            ]
        }
    ]
}
```

레몬 10개

시스템이 자동으로 다음 규칙을 추가합니다:

```json
{
    "item_keyword": "레몬",
    "conditions": [
        {
            "unit": "개",
            "store": "부엉이산장 마곡점",
            "target": "STOCK"
        }
    ]
}
```

## 🔧 고급 기능

### 중복 방지
- 이미 존재하는 매핑은 건너뜀
- 기존 규칙에 새로운 조건만 추가

### 품목 정규화
- 괄호 내용 자동 제거
- 숫자+단위 자동 제거
- 동의어 자동 매핑

### 매장 정보 추출
- `감자 10kg(강남)` → 감자, 10kg, 부엉이산장 강남점
- 자동으로 매장명 매칭

## 💡 활용 팁

### 새로운 공급업체 추가
새로운 공급업체가 생기면:
1. 해당 공급업체의 발주 데이터 준비
2. 학습 시스템 실행
3. 자동으로 매핑 추가됨

### 규칙 개선
분류가 잘못되는 경우:
1. 올바른 분류 결과 준비
2. 학습 시스템 실행
3. 규칙 자동 업데이트

### 정기적 학습
- 매주/매월 실제 데이터로 학습
- 시스템 정확도 지속적 향상

## 📈 학습 효과

학습 시스템을 사용하면:
- ✅ **정확도 향상**: 실제 데이터 기반 학습
- ✅ **시간 절약**: 수동 매핑 작업 불필요
- ✅ **자동 개선**: 지속적인 규칙 업데이트
- ✅ **오류 감소**: 일관된 분류 규칙
