# 경매가 입력 워크플로우

## 개요
가락시장 공공데이터 API에서 당일 경매 최고가/평균가를 조회하여
도크발주관리데이터.xlsx 단가 시트의 Col F(경매최고가), Col G(경매평균가)에 자동 입력한다.

## 실행 스크립트
`execution/fill_auction_from_api.py`

## 사용법
```bash
python execution/fill_auction_from_api.py \
  --master "G:/내 드라이브/1. 도크_주문 명세서/0. 매입단가_자료/도크발주관리데이터.xlsx" \
  --date 2026-02-23
```

### 파라미터
| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `--master` | O | 도크발주관리데이터.xlsx 경로 |
| `--date` | O | 단가시트 발주일 (YYYY-MM-DD) |
| `--auction-date` | X | 경매 API 조회일 (기본값: 발주일+1일) |

## 입력
- `도크발주관리데이터.xlsx` → "단가" 시트
- 대상 날짜 (발주일)

## 출력
- 단가 시트 Col F(경매최고가), Col G(경매평균가) 값 입력
- "흙" 표시 품목은 셀 서식 `#,##0"(흙)"` 적용 (숫자 값 유지)

## 단가 시트 구조
| Col | 내용 | 비고 |
|-----|------|------|
| A(1) | 구분 | 직납/재고, 소분/재고 |
| B(2) | 날짜 | YYYY-MM-DD |
| C(3) | 품목 | 품목명 (괄호 없는 기본형) |
| D(4) | 품위 | 등급 (특, 상, 상or대, 보통or중 등) |
| E(5) | 단위 | 4K, 15K, 1K, 12개 등 |
| F(6) | **경매최고가** | ← 이 스크립트가 채움 |
| G(7) | **경매평균가** | ← 이 스크립트가 채움 |
| H(8) | 식봄 | fill_sikbom_targeted.py가 채움 |
| I(9) | 매입가 | 수동/별도 |
| J(10) | 거래 업체 | 수동/별도 |

## 경매 API 날짜 규칙
경매는 발주일 당일~익일 새벽에 진행되며, API에는 **익일 날짜**로 등록된다.
- 예: 2/23 발주 → 경매 2/23~2/24새벽 → API `s_date=20260224`로 조회
- 스크립트가 자동으로 `--date + 1일`로 API 호출
- 수동 지정 필요시 `--auction-date` 사용

## API 정보
- URL: `http://www.garak.co.kr/homepage/publicdata/dataXmlOpen.do`
- 고정 파라미터: `id=6335`, `passwd=tfe7c1p4!!`, `dataid=data68`
- 가변 파라미터: `s_date`(경매일), `s_date_p`(전일), `s_date_p7`(7일전), `p_pos_gubun=1`(가락), `s_pum_nm=2`(청과), `s_pummok`(품목명)
- 인코딩: **UTF-8** (공식 문서에는 euc-kr이라 되어있지만 실제로는 UTF-8만 동작)
- 응답: XML (CDATA), regex로 파싱 (malformed XML 대응)
- 태그: PUM_NM(품목), G_NAME(등급), U_NAME(거래단위), MA_P(최고가), AV_P(평균가)

## 매칭 구조

### 1. ITEM_OVERRIDES (특수 매칭 — 우선 적용)
단위 변환, 필터링, 가격 비율 조정이 필요한 품목은 개별 규칙으로 처리한다.

| 품목 | API 검색어 | 매칭 대상 | 변환 | 비고 |
|------|-----------|----------|------|------|
| 깻잎(1KG) | 깻잎 | 깻잎 상 100속 | ×0.5 (50속 가격) | filter_item_exact로 깻잎순 제외 |
| 깻잎(4KG,큰잎) | 깻잎순 | 깻잎순 상 4KG상자 | ×1.0 | |
| 깐쪽파 | 깐쪽파 | 깐쪽파 특 10KG상자 | ×0.1 (1K 단가) | |
| 미나리 | 미나리 | 미나리 상 4KG | ×0.25 (1K 단가) | filter_item_exact로 돌미나리 제외 |
| 깐양배추45 | 양배추 | 양배추 특 8KG그물망 | ×1.0 | "흙" 표시 |
| 양상추(일반) | 양상추 | 양상추(일반) 상 12개 | ×1.0 | filter_item_contains로 수입 제외 |
| 깐마늘 대서 | 깐마늘 | 깐마늘 대서 20KG | 자동 변환 | use_sheet_grade + auto_convert_from_kg |

#### 깐마늘 동적 변환 (use_sheet_grade + auto_convert_from_kg)
시트 등급/단위를 읽어 자동 매칭 및 변환:
- 등급 "상or대" → API "상" 매칭, 등급 "보통or중" → API "보통" 매칭
- 단위 "1K" → factor = 1/20 = 0.05, 단위 "20K" → factor = 20/20 = 1.0

### 2. ITEM_SEARCH_MAP (일반 매칭)
Override에 없는 품목은 ITEM_SEARCH_MAP으로 API 검색어를 결정하고,
시트의 등급(Col D)과 단위(Col E)에 가장 가까운 결과를 자동 매칭한다.

### 3. ITEM_NOTES (흙 표시)
경매가 셀에 `#,##0"(흙)"` 서식 적용 (숫자 값은 유지):
- 깐양배추45, 깐양파, 깐대파

## 스킵/미매칭 처리
| 조건 | 처리 |
|------|------|
| 구분(Col A)에 "소분" 포함 | 스킵 (소분 행은 경매가 불필요) |
| ITEM_SEARCH_MAP 값이 None | 스킵 (레몬, 간마늘, 라디치오 — 경매 데이터 없음) |
| API 결과 0건 | no_match로 보고 |
| 중복 날짜 블록 | 첫 번째 연속 블록만 처리 (row gap > 2 시 중단) |

## 경매 데이터 없는 품목
| 품목 | 사유 | 대안 |
|------|------|------|
| 레몬 | 수입과일 | 식봄 가격 (다봄푸드 17kg 1박스) |
| 간마늘 | 가공품 | 식봄 가격 (다봄푸드 1kg 국내산) |
| 라디치오 | 수입 | 식봄 가격 (농장에서바로/쉐프의정원) |

## 파일 잠금 처리
엑셀 파일이 열려있으면 3초 간격으로 5회 재시도.
모두 실패 시 임시 경로(`%TEMP%/도크발주관리데이터_auction.xlsx`)에 저장하고 수동 복사 안내.

## 전체 단가 채우기 파이프라인
```
1) create_price_sheet.py       → 단가시트 행 생성
2) fill_auction_from_api.py    → 경매최고가/평균가 (Col F, G) ← 이 워크플로우
3) fill_sikbom_targeted.py     → 식봄 가격 (Col H)
```
