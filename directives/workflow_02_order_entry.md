# Workflow 2: 발주 시트 입력

## 목표
파싱된 일일 발주 내역을 마스터 엑셀 파일인 `도크발주관리데이터.xlsx`의 '발주' 시트에 자동으로 입력합니다.

## 입력
- **처리된 발주 데이터**: `data/inputs/processed_orders.txt`
- **대상 파일**: `도크발주관리데이터.xlsx` (구글 드라이브 또는 로컬 동기화 경로)
- **대상 시트**: '발주'

## 출력
- 마스터 엑셀 파일 업데이트 완료 (행 추가)

## 처리 로직 (Python)

### 1. 데이터 파싱
- `processed_orders.txt`에서 각 거래처별 품목, 수량, 단위를 추출합니다.
- 날짜는 실행 당일 날짜(YYYY-MM-DD)를 자동으로 부여합니다.

### 2. 시트 업데이트 방식
- **방법 A (API)**: 구글 시트/드라이브 API를 통해 원격 업데이트
- **방법 B (로컬)**: `pandas` 및 `openpyxl`을 사용하여 로컬 동기화된 엑셀 파일 직접 수정

### 3. 컬럼 구조 (작성 필요 예시)
| 날짜 | 거래처 | 품목 | 수량 | 단위 | 공급처 | ... |
|------|--------|------|------|------|--------|-----|
| 2026-01-28 | 샤브야키 분당점 | 청경채 | 4 | 박스 | 영운농산 | ... |

## 실행 스크립트
`execution/update_order_sheet.py`

## 주의 사항
- 중복 입력 방지 로직 (이미 해당 날짜/거래처 데이터가 있는지 확인)
- 비어 있는 행의 마지막을 찾아 데이터 추가
