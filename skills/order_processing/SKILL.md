# Order Processing Skill

이 스킬은 비정형/반정형 발주 데이터를 입력받아 표준화된 형식으로 변환하고, 
공급처별 매핑 규칙을 적용하여 배송 리스트(Excel)를 생성합니다.

## 기능

1.  **발주 데이터 파싱 (Parsing)**
    - 다양한 형식의 입력 텍스트(카카오톡, 문자 등)를 구조화된 데이터(거래처, 품목, 수량, 단위)로 변환합니다.
    - 정규식 및 퍼지 매칭을 활용하여 품목명을 식별합니다.

2.  **데이터 검증 (Verification)**
    - 추출된 데이터의 유효성을 검사합니다.
    - 등록되지 않은 거래처나 품목에 대해 경고를 발생시킵니다.
    - 단위(kg, 망, 박스 등) 및 품위 변환 로직을 수행합니다.

3.  **배송 리스트 생성 (Generation)**
    - 공급처별(영운농산, 다모아 등)로 품목을 분류합니다.
    - 요일별 배송 루트에 따라 페이지(시트)를 구성합니다.
    - 시각적 편의를 위해 조건부 서식(색상 하이라이팅)이 적용된 엑셀 또는 DOCX 파일을 생성합니다.

4.  **최종 정제본 DOCX 변환 (Final DOCX Conversion)**
    - 이미 정제된 최종 텍스트 데이터를 읽어 `python-docx`를 사용하여 배송 리스트를 생성합니다.
    - `page_config`에 따라 거래처(1-2p), 공급처(3p), 재고/시장(4p)을 분할 자동 배치합니다.
    - **색상 규칙**: 4페이지의 재고(빨강)/시장(파랑) 항목을 분석하여 1-2페이지의 해당 항목에도 동일한 색상을 자동 적용합니다.
    - **예외 사항**: '동원1차' 섹션은 어떠한 경우에도 색상을 적용하지 않고 검은색으로 유지합니다.

## 사용 방법

스킬 내 포함된 스크립트를 `execution` 레이어에서 호출하거나 직접 실행하여 사용합니다.

```python
# 최종 정제본을 DOCX로 변환 시
# execution/simple_docx_converter.py 실행
python execution/simple_docx_converter.py
```

## 스타일 가이드 (DOCX)

- **기본 폰트**: 맑은 고딕, 15pt
- **간격**: 섹션(공급처/거래처) 간 빈 줄은 엔터 1회로 제한 (중복 공백 금지)
- **배치**: 공급처 리스트(3p)는 라인 수에 따라 3개 컬럼에 균등하게 자동 분배 (신문 스타일)

## 파일 구조

- `scripts/`: 핵심 처리 로직이 담긴 파이썬 스크립트
- `execution/`: 직접 실행 가능한 변환 도구 (예: `simple_docx_converter.py`)
- `resources/`: 매핑 테이블(`mappings.json`) 및 텍스트 데이터
