## 문서 형식

### 레이아웃
- A4 세로, 3열 테이블
- 열 너비: 각 6.3cm (페이지 여백 고려하여 조정)
- 여백: 상하좌우 1cm
- 폰트: 맑은 고딕 14pt (강조: 볼드)
- 테두리: 검정 실선

### 거래처 섹션 형식
- 거래처명은 -로 시작, 굵게 표시
- 품목 사이 빈 줄로 거래처 구분

## 색상 처리 규칙

### 빨간색 (재고/창고소분)
재고소분 데이터에서 괄호 안 거래처 확인 → 해당 거래처 품목 빨간색
- 예: 팽이 15개(마곡) → 마곡점의 "팽이 15개" 빨간색
- 예: 쌀 2포(분당) → 분당점의 "쌀 2포" 빨간색

### 파란색 (시장구매/시장소분)
시장소분 데이터에서 괄호 안 거래처 확인 → 해당 거래처 품목 파란색
- 예: 감자 15kg(강남) → 강남점의 "감자 15kg" 파란색
- 예: 양상추 10통(분당) → 분당점의 "양상추 10통" 파란색

### 마지막 페이지 소분 섹션
- 재고/창고소분: 제목+품목 모두 빨간색
- 시장구매/시장소분: 제목+품목 모두 파란색
